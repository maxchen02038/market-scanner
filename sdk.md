# Market Scanner SDK

A small JavaScript client library that wraps the backend's HTTP API. Instead of
building URLs and parsing responses by hand, you call functions.

```js
const api = MarketScanner('http://localhost:3000');
const nvda = await api.score('NVDA', 'XLK');
console.log(nvda.score); // 44
```

> **SDK vs API:** the backend exposes an HTTP **API** (raw URLs returning JSON).
> This **SDK** is a thin wrapper over that API so callers use methods like
> `api.score('NVDA')` instead of `fetch('.../api/score/NVDA?etf=XLK')`. It also
> handles JSON parsing, timeouts, and error shaping for you.

## 1. Build & install

This is a proper package with a build step. Source lives in `src/`, and the
build produces distributable bundles in `dist/`.

### Building from source

```bash
cd sdk
npm install       # installs rollup (the bundler)
npm run build     # produces dist/
npm test          # runs the smoke test against the built bundle
```

`npm run build` produces four bundles from `src/index.js`:

| File | Format | For |
|---|---|---|
| `dist/index.cjs` | CommonJS | Node `require()` |
| `dist/index.mjs` | ESM | `import` in modern tooling |
| `dist/market-scanner-sdk.umd.js` | UMD | browser `<script>` (global `MarketScanner`) |
| `dist/market-scanner-sdk.umd.min.js` | UMD, minified | production `<script>` |

The correct file is selected automatically via the `main`, `module`, and
`browser` fields in `package.json`, so consumers don't pick manually.

### Using it

**Node (ESM):**
```js
import MarketScanner from '@market-scanner/sdk';
```

**Node (CommonJS):**
```js
const MarketScanner = require('@market-scanner/sdk');
```

**Browser:**
```html
<script src="dist/market-scanner-sdk.umd.min.js"></script>
<script>const api = MarketScanner('http://localhost:3000');</script>
```

There are no runtime dependencies — both Node 18+ and browsers have `fetch`
built in. Rollup is a **dev** dependency, needed only to build.

### Project layout

```
sdk/
├── src/index.js          source (edit this)
├── dist/                 built bundles (generated by npm run build)
├── test/smoke.test.cjs   smoke test
├── rollup.config.js      build config
└── package.json          scripts + entry points
```

## 2. Initialization

Create a client by giving it the backend's base URL.

```js
const api = MarketScanner('http://localhost:3000');       // local
const api = MarketScanner('https://your-backend-host');   // deployed
```

Optional settings:

```js
const api = MarketScanner('http://localhost:3000', {
  timeoutMs: 120000,   // default 90000 (90s)
});
```

A trailing slash on the URL is fine — it's trimmed automatically.

## 3. Methods

Every method returns a Promise.

| Method | Returns | Description |
|---|---|---|
| `health()` | `{ok, ts}` | Liveness check |
| `score(symbol, etf?)` | scored stock | Score one stock; `etf` sets sector weighting (default `XLK`) |
| `scan(etf)` | `{etf, name, count, stocks[]}` | Score a whole sector, ranked. Slow (~30–60s) |
| `report()` | report object | Latest `report.json` |
| `scoutData()` | scout object | Latest `scout-data.json` |
| `aiScout()` | AI picks object | Latest `ai-scout.json` |
| `aiInsights()` | insights object | Latest `ai-insights.json` |
| `data(file)` | file contents | Any allowed data file by name |
| `rebuild()` | `{ok, rebuilt}` | Force-regenerate report + scout data |
| `rebuildAI()` | `{ok, skipped?}` | Force-regenerate AI files |

`data(file)` only accepts: `report.json`, `scout-data.json`, `ai-scout.json`,
`ai-insights.json`. The `report()`, `scoutData()`, `aiScout()`, `aiInsights()`
methods are shortcuts for it.

## 5. Error handling

Failed requests throw. The thrown `Error` carries a `.status` and sometimes
`.retryAfter` (seconds, on rate limits).

```js
try {
  const s = await api.score('NVDA');
} catch (err) {
  console.error(err.message);   // e.g. "No price data for NVDA"
  console.error(err.status);    // e.g. 404, 429, 500, or 0 for timeout
  if (err.retryAfter) {
    // backend hit the Finnhub rate limit; wait and retry
  }
}
```

| `err.status` | Meaning |
|---|---|
| `0` | Request timed out |
| `404` | Symbol/sector not found, or data file not generated yet |
| `429` | Finnhub rate limit — see `err.retryAfter` |
| `500` | Server error |

## 6. Full examples

### Score a stock (browser)
```html
<script src="market-scanner-sdk.js"></script>
<script>
  const api = MarketScanner('http://localhost:3000');
  api.score('AAPL', 'XLK')
     .then(s => console.log(`${s.sym}: ${s.score}/100 (${s.dp}%)`))
     .catch(e => console.error(e.message));
</script>
```

### Rank a whole sector (Node)
```js
const MarketScanner = require('./market-scanner-sdk');
const api = MarketScanner('http://localhost:3000');

(async () => {
  const { stocks } = await api.scan('XLK');
  stocks.slice(0, 5).forEach(s => console.log(s.sym, s.score));
})();
```

### Read the AI picks with a freshness check
```js
const ai = await api.aiScout();
const ageHrs = (Date.now() - new Date(ai.generatedAt)) / 3600000;
console.log(`AI picks (${ageHrs.toFixed(1)}h old):`);
ai.picks.forEach(p => console.log(`  #${p.rank} ${p.sym} [${p.alignment}]`));
```

### Trigger a rebuild
```js
await api.rebuild();                    // report + scout data
const r = await api.rebuildAI();        // AI files
if (r.skipped) console.log('model server not reachable from the backend host');
```

## 7. Notes and limits

- **The backend must be running and reachable.** The SDK is only a client — it
  can't score anything on its own. Point it at a running backend.
- **`scan()` is slow** (~30–60s) because the backend batches requests to respect
  the Finnhub rate limit. Set a generous `timeoutMs` if you call it.
- **`rebuildAI()` may return `{skipped:true}`** — that means the backend's host
  can't reach the model server (expected off the office network). Not an error.
- **CORS:** in the browser, the backend must allow your page's origin. The
  backend's `FRONTEND_ORIGIN` env var controls this.
- The SDK adds a cache-busting `?t=` to data-file requests so you always get the
  latest generated copy.
